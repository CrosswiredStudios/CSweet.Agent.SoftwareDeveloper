# 1.1.0

- Daniel can receive an explicit Hello World test-instance request in chat and create a durable personal task for it.
- The task requests an ephemeral Linux VM, writes a Python Hello World application, starts its guest service, verifies HTTP health, and returns the provider's local browser URL and expiry.
- Compute events advance the task. Stable provisioning, command and publication keys prevent duplicate effects after restarts; unknown command outcomes are reported without blind retries.
- Added computeWorkstreamId and computeTemplateId settings. Installation capability approval and separate scoped compute/inbound/port-8080 grants are required.
- Requires the updated Core/provider/guest runtime and an operator-prepared Ubuntu 24.04 template with Python 3. The test link is local to the compute host, lasts up to one hour, and closes on provider shutdown or VM teardown. Public internet deployment remains outside this MVP.
