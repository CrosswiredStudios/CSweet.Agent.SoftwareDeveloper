# 1.13.1

- When every failed check failed only because its tool isn't installed in the runtime (exit 127 or 9009,
  "command not found", "is not recognized as ..."), the stage is now Blocked as a `decision-required:v1`
  environment decision naming the missing tools and the options: provide the toolchain in the agent runtime,
  or amend the ticket's validation. Previously it was a generic validation failure that nobody picked up
  (VGF943299B17-6 sat Blocked on `node -v`). Real check failures still stay with the developer.
- No new capabilities, grants or network access.
