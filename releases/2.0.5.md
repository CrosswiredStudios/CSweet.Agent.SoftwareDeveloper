# 2.0.5

- Bound workspace commands to five minutes and cleanup to ten seconds; stop model continuation when a command times out.
- Run each command in a fresh confined shell. Preserve the last completed source checkpoint and require isolated-runtime replacement before a bounded retry.
- Keep timeouts separate from code-validation failures and route exhausted recovery to management. Run CI stages separately so the failing stage stays visible.

Requires the matching C-Sweet timeout-recovery host update. Existing runtimes must be replaced to load this version. No new permissions or configuration are required.
