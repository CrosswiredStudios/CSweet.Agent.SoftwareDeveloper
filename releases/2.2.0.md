# 2.2.0

Add `semantic_code_search`, an offline semantic code search tool backed by the image's `sgrep`. Use it to find code by what it does when its name is unknown; exact identifiers still use grep through `execute_workspace_command`.

- Discovery mode searches a workspace-relative path; an optional ripgrep `pattern` (and `glob`) reranks matching lines by meaning instead.
- Results are `path:start-end` excerpts, at most 20 hits, each cut at 4000 bytes and the whole response kept below the 32 KiB shell output limit.
- Every argument is passed as a quoted literal. Paths cannot leave the workspace. A query that names a protected command pattern is rejected before execution and does not count toward workspace policy denials.
- Searches run with a 120 second limit. A slow, failed or unparseable search returns a tool error that suggests grep; it never stops coding or requires a runtime replacement.
- Searches are inspection context only. They are never validation evidence, never trigger build resource sizing and never create source checkpoints. The search cache lives outside the workspace.

Requires a certified Office development guest image that ships `/usr/local/bin/sgrep` with its offline model cache (CSweet.Office 0.15.0 or later). On older images the tool is simply absent and its guidance is not shown. No manifest, grant, configuration or credential change. Shares execution behavior and regression coverage with Video Game Engineer 4.2.0.

Install through the normal Installed Agents update flow.
