# 1.15.2

Release build-readiness no longer requires hiring a separate Build Release Engineer. This agent advertises work.execution.build-readiness.v1 alongside V2 execution and handles the assigned gate through SDK DeliveryBuildReadiness. Build execution uses certified provider recipes and the exact authorized release candidate; pending builds return durable IDs and resume through platform events. Independent QA, technical review and manager acceptance remain required. No host tools, deployment or public release authority is added.

Requires SDK 3.63.0 to be published before this agent release. Publication, installation and live testing are owner-operated.
