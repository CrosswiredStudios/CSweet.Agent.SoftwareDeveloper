# 2.1.7

Reduce small-ticket model turns with bounded ordered command batches, individual exit-code receipts and a durable checkpoint after each command. File tools write UTF-8 without an implicit BOM, avoiding JSON and executable-script repair loops. Preserve scope, configured token budgets, technical review and independent QA.

Recover HTTP 502/503/504 and legacy MCP gateway errors from retained files in a fresh model session, with bounded backoff. Checkpoint uploads retry their existing content-addressed operation without replaying commands. Exhausted gateway recovery returns a retryable runtime.transport failure instead of a terminal Blocked outcome. Authority rejection, cancellation, failed validation and unsafe checkpoint failures still stop execution.
