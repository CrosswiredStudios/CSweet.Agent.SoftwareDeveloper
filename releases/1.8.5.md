# 1.8.5

- Blocked development tasks now identify the failed step, reported error or failing check, and a concrete recovery action. Platform failures include the capability and failure code.
- Exhausted task validation attempts preserve the failed command and diagnostic instead of the generic development-run message. Unknown compute outcomes no longer claim a Docker build or test failure without evidence.
- Owner-facing excerpts are bounded and redact common credential forms, endpoint URLs, host paths, and stack traces.
- No new grants or configuration are required. Update Daniel to 1.8.5 for future blocker reports. The accompanying C-Sweet update preserves full blocker reports in ticket comments and renders their Markdown. Existing historical comments are unchanged.
