# 0.9.0

Adds a separate typed web-preview.manage.v1 callback for private builds, owner-grant requests, preview lifecycle, renewal, browser checks and diagnostics. New platform capability declarations require installation upgrade review and a scoped hosting grant. The existing coding harness retains its current shell and delivery limits. Sibling plugin/SDK clones are detected for local development; package-only builds remain supported.

Adds durable preview-change handling, current-state refresh on delayed/duplicate notifications, and a paginated list callback for recovery after missed events.
